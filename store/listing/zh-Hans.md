## Short description

适用于 Windows 的显示器配置文件。为每台显示器调整伽马、对比度、亮度、色温和鲜艳度,并通过快捷键、按应用或像夜间模式那样按计划切换。

## Description

有了 DispHub,只需一个快捷键就能切换屏幕的观感。

为每种场景创建一个配置文件(竞技游戏用更亮的暗部和更浓的色彩,深夜阅读用温暖柔和的画面,修图用中性色彩),随时一键切换。屏幕上的小消息会确认切换,且不会抢走游戏的焦点。

适合你使用电脑方式的配置文件
• 为每台已连接的显示器调整亮度、对比度、伽马和色温
• 在笔记本和大多数显示器上直接调整屏幕自身亮度,无需按显示器按键
• 在 NVIDIA、Intel 和 AMD 显卡上调整鲜艳度(色彩饱和度),包括大多数笔记本的内置屏幕
• 适合直播:OBS、Discord 和截图记录的是你的正常颜色(采集卡会显示配置文件效果)
• 每个配置文件都可设置全局快捷键,还可设置开关以及下一个和上一个配置文件
• 从通知区域快速切换

模板与分享
• 从现成的游戏、电影和夜间阅读配置文件开始
• 把你的配置文件分享为任何人都能打开的链接,DispHub 一键即可添加

自动化(DISPHUB PRO,首周免费)
• 按应用切换的配置文件:游戏或应用在前台时使用它自己的效果,切换离开后桌面恢复正常(免费版支持一个应用)
• 像 Windows 夜间模式一样的计划:从日落到日出或在固定时间,带平滑过渡
• 暗部增强:看清暗处细节,而不让整个画面发灰
• 每台显示器使用不同设置
• 可设置显示器亮度、刷新率和 HDR 的配置文件
• 笔记本屏幕在使用电池时降低刷新率
• 无限配置文件

安全又轻巧
• 任何更改之前都会保存原始颜色,在关闭或退出 DispHub 时恢复,即使程序崩溃后也会恢复
• 在通知区域安静运行,内存占用极低
• 无需账户,无广告,无遥测

可免费试用全部 Pro 功能 7 天。之后 DispHub 仍可免费使用三个配置文件和一个应用配置文件。一次性购买 Pro 即可保留按应用切换的配置文件、计划、每台显示器的设置和无限配置文件,同时支持开发。DispHub 在 GitHub 上开源。

注意:Windows 开启 HDR 时无法使用基于伽马的调整。Windows 默认会限制颜色的调整幅度;在你同意后,DispHub 可以为非常暖的夜间配置文件解除这一限制。
