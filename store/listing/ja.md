## Short description

Windows のディスプレイ プロファイル。ディスプレイごとにガンマ、コントラスト、明るさ、色温度、鮮やかさを調整し、ホットキー、アプリごと、または夜間モードのようなスケジュールで切り替えられます。

## Description

DispHub なら、ホットキー 1 つで画面の見た目を切り替えられます。

場面ごとにプロファイルを作り (対戦ゲーム用に暗部を明るく色を強めに、深夜の読書用に暖かく暗めに、写真の作業用にニュートラルに)、すぐに切り替えられます。小さな画面上のメッセージが、ゲームからフォーカスを奪わずに切り替えを知らせます。

使い方に合わせたプロファイル
• 接続されたすべてのディスプレイの明るさ、コントラスト、ガンマ、色温度
• ノート PC やほとんどのモニターで、ボタンに手を伸ばさずに画面自体の明るさを調整
• NVIDIA、Intel、AMD のグラフィックスで鮮やかさ (彩度) を調整。ほとんどのノート PC の内蔵画面にも対応
• 配信にも安心: OBS、Discord、スクリーンショットには通常の色が記録されます (キャプチャ カードではプロファイルが反映されます)
• プロファイルごとのグローバル ホットキーに加え、オン/オフ、次と前のプロファイル
• 通知領域からすばやく切り替え

テンプレートと共有
• ゲーム、映画、夜の読書向けの既製プロファイルから始められます
• 自分のプロファイルを誰でも開けるリンクとして共有でき、DispHub ならワンクリックで追加できます

自動化 (DISPHUB PRO、最初の 1 週間は無料)
• アプリごとのプロファイル: ゲームやアプリが前面にある間はその見た目になり、切り替えるとデスクトップは元に戻ります (無料で 1 つのアプリに対応)
• Windows の夜間モードのようなスケジュール: 日の入りから日の出まで、または指定した時刻に、なめらかなフェードで
• シャドウ ブースト: 画面全体を白っぽくせずに暗い部分を見やすく
• ディスプレイごとの設定
• モニターの明るさ、リフレッシュ レート、HDR を設定するプロファイル
• ノート PC の画面ではバッテリー駆動時に低いリフレッシュ レート
• 無制限のプロファイル

安全で軽量
• 変更前に元の色を保存し、DispHub をオフにしたときや終了したとき、クラッシュ後でも元に戻します
• 通知領域で静かに動作し、メモリ使用量はごくわずか
• アカウント不要、広告なし、テレメトリなし

すべての Pro 機能を 7 日間無料でお試しいただけます。その後も DispHub は 3 つのプロファイルと 1 つのアプリ プロファイルで無料で使えます。買い切りの Pro にアップグレードすると、すべてのアプリのプロファイル、スケジュール、ディスプレイごとの設定、無制限のプロファイルが使え、開発の支援にもなります。DispHub は GitHub で公開されているオープンソースです。

注意: Windows の HDR がオンの間は、ガンマによる調整は使えません。Windows は既定で色の変更幅を制限していますが、DispHub はとても暖かい夜用プロファイルのために、許可を得てこの制限を解除できます。

## Product features

1. 明るさ、コントラスト、ガンマ、色温度、鮮やかさのプロファイル
2. ゲーム中でもプロファイルを切り替えられるグローバル ホットキー
3. NVIDIA、AMD、Intel のグラフィックスで鮮やかさを調整 (ノート PC の画面にも対応)
4. 接続されたすべてのディスプレイで動作
5. プロファイル テンプレートと共有リンク
6. 自動で切り替わるアプリごとのプロファイル (1 つは無料、Pro ならすべてのアプリ)
7. 日の入り、日の出、指定した時刻にプロファイルをなめらかに切り替えるスケジュール (Pro)
8. 暗い部分を見やすくするシャドウ ブースト (Pro)
9. ディスプレイごとの設定 (Pro)
10. 一時停止、終了、クラッシュ後に元の色を復元
11. ライト テーマとダーク テーマ、Windows と同時に起動
