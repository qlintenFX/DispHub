# Preset gallery

`gallery.json` is the list shown on DispHub's Presets page. To add a preset:

1. Make the profile in DispHub, then click **Share** to copy its link.
2. Add an entry to `gallery.json` with a short `name` (40 characters at most), a one-sentence `description`,
   a few `tags` (games or uses) and the `link`.
3. Open a pull request. Say which monitor and game you tuned it on.

Presets that need the full colour range or HDR off should say so in the description.
