Build it from source. DispHub is free software under the GPL v3.0 or later. Builds from source include every feature, but they don't update themselves and aren't signed for the Microsoft Store. You need Windows 10 (version 2004) or later and the .NET 10 SDK.

cd DispHub
dotnet run --project src/DispHub
