# Code of conduct

DispHub follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Report unacceptable behaviour
privately through [GitHub's private reporting](https://github.com/qlintenFX/DispHub/security/advisories/new);
reports are handled confidentially.
